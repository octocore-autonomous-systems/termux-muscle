# Termux Muscle 0.3.0

Termux Muscle 0.3.0 adds read-only `termux-muscle migration` advisories for common settings and executable path conflicts. It also requires an isolated non-conversational Claude initialization check before accepting a new runtime. The manager never runs that check with your account settings, hooks or plugins; ordinary Claude launches continue to use your own configuration.

`termux-muscle self-update` now prints a notice and succeeds without reinstalling when the published or requested management version is equal to or older than the installed one. Use `-f` or `--force` for an intentional compatible reinstall or downgrade. Forced updates still verify the installer and source, and versions below 0.2.0 remain incompatible with the current manual ownership format. Claude runtime `rollback` is separate.

Install the published release in native ARM64 Termux:

```sh
curl -fsSL https://github.com/octocore-autonomous-systems/termux-muscle/releases/download/v0.3.0/install.sh | sh
```

The pinned, unmodified Claude Code 2.1.270 and musl 1.2.6-r2 payloads are unchanged. [Fresh device evidence](../../compatibility/galaxy-s26-ultra-0.3.0-20260924.md) records private source installation, isolated startup, offline update and rollback, clean removal and one authenticated Sonnet 5 shell-tool workflow on a Galaxy S26 Ultra running Android 16 and Termux 0.118.3. This run did not retest command takeover, indexed manual discovery, interactive or background use, MCP tool calls or other models; earlier release reports remain available with their dates and scope. Public installer delivery will be checked after publication.
