# Termux Muscle 0.6.0

This version shows signs of life during a quiet `self-update`. The Claude Code pin stays at **2.1.283** and musl at **1.2.6-r2**.

## Live progress

In 0.5.x, the build and some test programs ran for many seconds without any change on screen, so a slow step looked like a stall. On a terminal, 0.6.0 adds:

```text
Building Termux Muscle locally... / 14s
Running test programs: .. \ 3/15 test_acquire.sh 12s
```

- The build shows a spinner and its elapsed seconds.
- During tests, the status after the dots shows the running program, its position and its elapsed seconds. On a narrow terminal, the program name is dropped first.
- Each status line is erased when its step ends, leaving the same stage lines, dots and totals as before:

```text
Building Termux Muscle locally...
Running test programs: ...............
Tests: 15 passed, 0 skipped, 0 failed.
```

A dot still means one passed test program; nothing is printed on a timer. When the progress output is not a terminal (a log, CI or a `--json` transcript), the output is exactly the 0.5.1 dots and totals. Set `TM_SELF_UPDATE_PROGRESS_LIVE=0` to turn the live status off.

The status stops at the end of each step, on failure and on HUP, INT and TERM, and it also stops by itself if its installer or test runner disappears. The downloaded installer and test runner draw it, so a 0.5.1 manager shows it on its update to 0.6.0.

## Device evidence

[Dated device evidence](../../compatibility/galaxy-s26-ultra-0.6.0-20260927.md) from a Samsung Galaxy S26 Ultra (Android 16, Termux 0.118.3) covers `make check` run as a quiet self-update runs it, on a real terminal: the maintainer watched the spinner, program position and elapsed seconds advance, and the finished output was the same dots and totals as 0.5.1 (all 15 test programs passed, outer event file untouched). Maintainer acceptance covered private source installation, isolated startup, offline update and rollback, removal and one bounded authenticated **Opus 5.5** shell-tool workflow, with the live installation unchanged.

Run acceptance from a **fresh native Termux shell that is not inside Claude Code**, in a clean checkout of the release commit:

```sh
scripts/maintainer_acceptance.sh --model claude-opus-5-5
```

## Updating an existing installation

From a fresh Termux shell:

```sh
termux-muscle self-update
```
