# Termux Muscle 0.10.0

The default Claude Code pin moves from **2.1.284** to **2.1.285**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.285](https://github.com/anthropics/claude-code/releases/tag/v2.1.285) adds plugin configuration commands and fixes startup when managed settings cannot be read due to permissions, SSH executable selection during plugin updates, and synchronous hooks whose background processes keep output open. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.284** is retained as formerly pinned by Termux Muscle **0.8.0 to 0.9.0**, using the [0.9.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.9.0-20260929.md). The current pin starts with **0.10.0**. Earlier history is unchanged.

## Device evidence

[Fresh device evidence](../../compatibility/galaxy-s26-ultra-0.10.0-20260929.md) from Samsung Galaxy S26 Ultra, Android 16 / API 36, Termux 0.118.3 (GitHub) records all **15 C and shell test programs passing** in a native shell and acceptance from clean commit `efcf02e`. Private source install, isolated version/help/init, shell namespace, offline update and rollback, and uninstall passed with the live installation unchanged.

One bounded authenticated **Opus 5.5** (`claude-opus-5-5`) request produced exactly one successful Bash-tool fixture call, verifying native shell, portable shebang and ripgrep. The exact model was observed; capture exited 0 in 6068 ms.

The optional runtime host probes and unavailable cross-UID executable fixture were skipped in the deterministic suite; real vendor startup and namespace checks passed separately during acceptance. Public HTTPS delivery and command/manual takeover were not retested. Sonnet 5.5 and Fable 5.1 remain documented, not verified.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.285 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
