# Termux Muscle 0.20.0

The default Claude Code pin moves from **2.1.295** to **2.1.296**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.296](https://github.com/anthropics/claude-code/releases/tag/v2.1.296) is a large upstream release. Among its changes, subagent definitions gain `autoCompactWindow`, the Read tool gains an `allow_large` option for reading a whole text file past the usual size limits, and `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` sets a longer maximum backoff when an overloaded request is retried. It fixes Edit and NotebookEdit replacing every non-ASCII character in files that are not valid UTF-8 (such edits are now refused), Bash permission checks auto-approving some commands that assign and then use `BASH_ARGV0`, headless sessions starting an MCP server that was switched off for the folder, an Esc or interrupt during a `UserPromptSubmit` hook ending headless sessions or letting the unchecked prompt through, and secret redaction in shared transcripts and debug logs missing some values. The default limit on MCP tool descriptions and server instructions rises from 2,048 to 4,096 characters. When this release was prepared, 2.1.296 was the version both Anthropic's download channel and npm's `latest` tag named. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.295** is retained as formerly pinned by Termux Muscle **0.19.0**, using the [0.19.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.19.0-20261008.md). The current pin starts with **0.20.0**. Earlier history is unchanged.

## Device evidence

[Fresh device evidence](../../compatibility/galaxy-s26-ultra-0.20.0-20261009.md) from Samsung Galaxy S26 Ultra, Android 17 / API 37, Termux 0.118.3 (GitHub) records all **15 C and shell test programs passing** in a native shell and acceptance from clean commit `b245cf2`. Private source install, isolated version/help/init, shell namespace, offline update and rollback, and uninstall passed with the live installation unchanged.

One bounded authenticated **Opus 5.5** (`claude-opus-5-5`) request produced exactly one successful Bash-tool fixture call, verifying native shell, portable shebang and ripgrep. The exact model was observed; capture exited 0 in 5782 ms.

The optional runtime host probes and unavailable cross-UID executable fixture were skipped in the deterministic suite; real vendor startup and namespace checks passed separately during acceptance. Public HTTPS delivery and command/manual takeover were not retested. Sonnet 5.5 and Fable 5.1 remain documented, not verified. Claude Code 2.1.296 exposed no Termux Muscle defects; this release changes no harness code.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.296 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
