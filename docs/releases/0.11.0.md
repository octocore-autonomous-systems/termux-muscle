# Termux Muscle 0.11.0

The default Claude Code pin moves from **2.1.285** to **2.1.286**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.286](https://github.com/anthropics/claude-code/releases/tag/v2.1.286) fixes `--resume` and `--continue` losing turns after a crashed session with parallel tool calls, API 400 errors after non-text tool or hook results, several credential-masking gaps in error messages and redacted transcripts, repeated login prompts when cloud credentials expire, and a range of MCP, subagent and Remote Control issues. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.285** is retained as formerly pinned by Termux Muscle **0.10.0**, using the [0.10.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.10.0-20260929.md). The current pin starts with **0.11.0**. Earlier history is unchanged.

## Device evidence

Fresh device and authenticated tool acceptance is pending. This preparation does not assert verification for 0.11.0.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.286 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
