Termux Muscle is an independent OAS community project for installing, running and maintaining Claude Code on native ARM64 Termux.

This initial release pins **Claude Code 2.1.270** and **musl 1.2.6-r2**. Tested on **Samsung Galaxy S26 Ultra (SM-S948U), Android 16 / API 36, Termux 0.118.3 from GitHub**. The original Anthropic executable remains unmodified; our Bash/C manager is built locally.

Installation, startup, authenticated shell tools, updates, failed-update preservation, offline repair/rollback and removal passed. Command hooks, local stdio MCP initialization and interactive startup also passed. [Read the device evidence and exact package versions](https://github.com/octocore-autonomous-systems/termux-muscle/blob/v0.1.0/compatibility/galaxy-s26-ultra-20260914.md).

**Model results:** Opus 5 and Sonnet 5 passed exact authenticated checks. Fable 5.1 answered a direct launcher check, while automated probes encountered upstream fallback/refusal; these mixed observations remain visible in the report. Default cross-session messaging was disabled by a vendor UID-mapping check. Background/screen-off behavior and actual MCP tool invocation are untested.

```sh
curl -fsSL https://github.com/octocore-autonomous-systems/termux-muscle/releases/download/v0.1.0/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
termux-muscle run
```

Have another Android device or Termux version? Run `termux-muscle test --output report.json`, review it, and [share a device compatibility report](https://github.com/octocore-autonomous-systems/termux-muscle/issues/new?template=device-compatibility.yml). Nothing uploads automatically.
