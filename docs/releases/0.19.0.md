# Termux Muscle 0.19.0

The default Claude Code pin moves from **2.1.294** to **2.1.295**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.295](https://github.com/anthropics/claude-code/releases/tag/v2.1.295) is a large upstream release. Among its changes, command and HTTP hooks gain `onFailure: "block"`, so a hook that cannot start, times out or exits with an unexpected code blocks the action instead of letting it through. It fixes `claude -p` text output dropping earlier responses when background work started another turn, a skill's `allowed-tools` and `effort` being dropped in `-p` runs, Bash tool calls failing when the model passes `command_description` instead of `description`, a file being treated as already read after a Bash command ran without printing it, and the terminal freezing on very long responses or while highlighting code with very long lines. It also fixes remote MCP servers staying disconnected after an outage in headless sessions. When this release was prepared, 2.1.295 was the version both Anthropic's download channel and npm's `latest` tag named. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.294** is retained as formerly pinned by Termux Muscle **0.18.0**, using the [0.18.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.18.0-20261008.md). The current pin starts with **0.19.0**. Earlier history is unchanged.

## Device evidence

Fresh device and authenticated tool acceptance is pending. This preparation does not assert verification for 0.19.0.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.295 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
