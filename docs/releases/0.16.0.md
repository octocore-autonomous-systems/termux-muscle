# Termux Muscle 0.16.0

The default Claude Code pin moves from **2.1.291** to **2.1.292**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.292](https://github.com/anthropics/claude-code/releases/tag/v2.1.292) adds `claude plugin install --marketplace <source>`, an `effort` parameter on the Agent tool and the `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` environment variable for a longer backoff on overloaded (529) requests. It closes several permission and sandbox gaps: PreToolUse hook approvals and auto mode bypassing the permission prompt for file reads from network (UNC) paths, sandboxed commands reading the staged copies of `/ultrareview` uploads, subagents with `permissionMode: auto` entering auto mode when it is unavailable, and a tampered on-disk cache of server-managed settings switching off the built-in policy plugin. It also fixes one-shot `claude -p` and Agent SDK runs stopping a background command 5 seconds after the final result or dropping a scheduled wakeup, saved scheduled tasks never firing after `/resume`, `/branch` or `/clear`, `NO_PROXY` being ignored for Claude Code's own API requests, an MCP tool with a name longer than 128 characters making every request fail, Grep and Glob reporting no matches for an unreadable path, and plan mode not being restored on resume, plus a range of plugin, mod, vim mode and cloud session issues. Local (stdio) MCP server connections now negotiate protocol version 2026-07-28 by default, and `claude -p` starts its first turn without waiting for HTTP and SSE MCP servers. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.291** is retained as formerly pinned by Termux Muscle **0.15.0**, using the [0.15.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.15.0-20261006.md). The current pin starts with **0.16.0**. Earlier history is unchanged.

## Device evidence

Fresh device and authenticated tool acceptance is pending. This preparation does not assert verification for 0.16.0.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.292 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
