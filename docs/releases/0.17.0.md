# Termux Muscle 0.17.0

The default Claude Code pin moves from **2.1.292** to **2.1.293**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.293](https://github.com/anthropics/claude-code/releases/tag/v2.1.293) adds Claude Haiku 5.5 (`claude-haiku-5-5`) as the default Haiku model on the Anthropic API, `agentType` in the `subagentStatusLine` payload and `isDeferred` on `$.tool.register` for mods. It fixes Claude treating its own last actions before a context compaction as done and then retracting or redoing finished work, a memory leak where an HTTP MCP connection kept every request it had sent until it closed, a message sent while Claude was working being lost when `←` moved the session to the background, path-scoped rules and nested CLAUDE.md files not loading when a file is viewed with a single-file `cat`, `head`, `tail`, `sed -n` or `grep` command, `claude logs`, `stop`, `kill`, `rm` and the `claude daemon` commands sometimes signing the user out near login expiry, and `claude purge` stopping silently when a file could not be deleted, plus a range of subagent, plugin, mod, vim mode, Remote Control and Claude in Chrome issues. It reverts the 2.1.281 auto mode denial message change and the 2.1.290 fix for cloud sessions staying asleep after a container restart lost a pending wakeup, and claude.ai skill syncing now checks for changes about every 40 minutes instead of every 10 while no session is in use. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.292** is retained as formerly pinned by Termux Muscle **0.16.0**, using the [0.16.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.16.0-20261006.md). The current pin starts with **0.17.0**. Earlier history is unchanged.

## Device evidence

Fresh device and authenticated tool acceptance is pending. This preparation does not assert verification for 0.17.0.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.293 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
