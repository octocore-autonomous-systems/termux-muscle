# Termux Muscle 0.3.1

This release fixes the 0.3.0 public installer's local test phase when it is launched by an older installed manager. The older manager exports its helper path; 0.3.0's migration test accidentally selected that helper and stopped safely before replacing the manager. Version 0.3.1 explicitly tests the newly compiled helper from the downloaded source. The 0.3.0 tag, release and assets remain intact.

Run in native ARM64 Termux:

```sh
termux-muscle self-update --version 0.3.1
```

For a new installation:

```sh
curl -fsSL https://github.com/octocore-autonomous-systems/termux-muscle/releases/download/v0.3.1/install.sh | sh
```

The 0.3.0 migration advisories, isolated non-conversational startup gate and self-update version comparison are included. The manager skips equal or older releases with a notice; `-f` or `--force` permits an intentional compatible reinstall or downgrade while preserving checksum and ownership checks. In-place changes below 0.2.0 remain unsupported.

The pinned, unmodified Claude Code 2.1.270 and musl 1.2.6-r2 payloads are unchanged. [Dated device evidence](../../compatibility/galaxy-s26-ultra-0.3.1-20260924.md) records the fresh 0.3.1 scope. Prior reports retain their release identities and dates. Interactive and background use, MCP tool calls and other models are outside this release's fresh acceptance scope.
