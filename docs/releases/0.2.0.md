Termux Muscle 0.2.0 makes normal installation provide the familiar `claude` command. After the runtime passes validation, it registers the Termux prefix and home-bin commands plus the first existing executable `claude` found elsewhere on PATH. Existing commands are backed up; uninstall restores them only while their installed replacements remain unchanged and owned. Later foreign changes and necessary restoration evidence are preserved.

```sh
curl -fsSL https://github.com/octocore-autonomous-systems/termux-muscle/releases/download/v0.2.0/install.sh | sh
claude auth login
claude
man termux-muscle
```

The installer provides the management command in the prefix and home-bin directories and installs one indexed regular manual using Termux `mandoc`. Unrelated manager commands and manuals are preserved. `--no-link` opts out of Claude command setup; `--no-install` installs only the management tool and manual. Shell aliases/functions and cached locations remain under the user's control.

The new manager rejects self-update requests below 0.2.0 because older managers cannot read regular-manual ownership records. Do not run an old installer over a newer installation: direct execution bypasses that check and can partially replace tooling. For an intentional manager downgrade, uninstall with the current manager first. `termux-muscle rollback` restores a previous **Claude Code runtime**, independently of the management-tool version.

Version 0.2.0 retains the unmodified **Claude Code 2.1.270** executable and **musl 1.2.6-r2**. Fresh [native device evidence](https://github.com/octocore-autonomous-systems/termux-muscle/blob/v0.2.0/compatibility/galaxy-s26-ultra-0.2.0-20260915.md) covers **Samsung Galaxy S26 Ultra / SM-S948U, Android 16 / API 36, security patch 2026-08-05, Termux 0.118.3 from GitHub**, with nineteen exact package versions including `mandoc` 1.14.6-7.

Actual isolated source bootstrap, automatic executable-command takeover, startup, namespace shell/shebang/ripgrep, indexed manual installation/refresh/removal, update/rollback, failed-update preservation, offline repair and complete removal passed. A separate bounded **Sonnet 5** session passed exact authenticated model and actual Bash-tool checks, with matching independent evidence for native shell, portable shebang, ripgrep and a nested launcher. The report records each run's scope and timestamps. Live-host command entries were not changed by these tests.

**Model/feature limits:** Sonnet 5 is the only newly verified model in 0.2.0. The unchanged [0.1.0 report](https://github.com/octocore-autonomous-systems/termux-muscle/blob/v0.1.0/compatibility/galaxy-s26-ultra-20260914.md) retains Opus 5/Sonnet 5 PASS results and a direct Fable 5.1 response with automated upstream fallback/refusal. Opus and Fable were not reverified for 0.2.0. No Opus 5.1 identity or universal Fable success was established. The prior default cross-session messaging UID-mapping failure remains documented; background/screen-off behavior and actual MCP tool invocation remain unverified.

Other Android devices and Termux versions are welcome: run `termux-muscle test --output report.json`, review it, and [share a device compatibility report](https://github.com/octocore-autonomous-systems/termux-muscle/issues/new?template=device-compatibility.yml). No automatic uploads or paid model requests occur in default checks.
