# Termux Muscle 0.14.0

The default Claude Code pin moves from **2.1.288** to **2.1.289**. Musl stays at **1.2.6-r2**. The official vendor executable is unmodified; the npm archive integrity and extracted binary digest are recorded in `compatibility.json`.

## Why

[Claude Code 2.1.289](https://github.com/anthropics/claude-code/releases/tag/v2.1.289) adds `agent.spawn` for teammates, one agent id across plugin hook events and idle and waiting states in `$.agent.list()`, and fixes Bash deny and ask rules being skipped under sandbox auto-allow behind an environment variable prefix or a bare variable assignment, a deny or ask rule on a nested part of a compound shell command not holding over a user-installed mod's approval, `Read` deny rules not applying to files reached through a symlink in the IDE, a user-installed plugin being able to rewrite the descriptions of an organization-managed MCP server's sign-in tools, the terminal freezing on short code blocks with many unclosed `<script>` tags, and installed mods not loading in the first session after an upgrade, plus a range of plugin, mod rendering and `claude plugin validate` issues. These are upstream changes; Termux Muscle acceptance tests the lifecycle and the bounded tool workflow described below, not every upstream feature.

## Pin history

Claude Code **2.1.288** is retained as formerly pinned by Termux Muscle **0.13.0**, using the [0.13.0 maintainer report](../../compatibility/galaxy-s26-ultra-0.13.0-20261002.md). The current pin starts with **0.14.0**. Earlier history is unchanged.

## Device evidence

[Fresh device evidence](../../compatibility/galaxy-s26-ultra-0.14.0-20261004.md) from Samsung Galaxy S26 Ultra, Android 17 / API 37, Termux 0.118.3 (GitHub) records all **15 C and shell test programs passing** in a native shell and acceptance from clean commit `d33ec4f`. Private source install, isolated version/help/init, shell namespace, offline update and rollback, and uninstall passed with the live installation unchanged.

One bounded authenticated **Opus 5.5** (`claude-opus-5-5`) request produced exactly one successful Bash-tool fixture call, verifying native shell, portable shebang and ripgrep. The exact model was observed; capture exited 0 in 5595 ms.

The optional runtime host probes and unavailable cross-UID executable fixture were skipped in the deterministic suite; real vendor startup and namespace checks passed separately during acceptance. Public HTTPS delivery and command/manual takeover were not retested. Sonnet 5.5 and Fable 5.1 remain documented, not verified. Claude Code 2.1.289 exposed no Termux Muscle defects; this release changes no harness code.

## Updating an existing installation

After this release is published, run from a native Termux shell:

```sh
termux-muscle self-update
termux-muscle update
claude --version
```

The final command should report `2.1.289 (Claude Code)`. A previous validated runtime remains available through `termux-muscle rollback`.

## Known limitations

Acceptance covers one device and configuration. Interactive UI, background and screen-off operation, custom hooks, MCP tool calls, and other models require separate evidence. Documented model minimums and account entitlements are unchanged. Installing any version other than the current pin still requires `--allow-unverified`.
